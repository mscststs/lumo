# Privacy Policy

**Lumo — AI-Powered Browser Sidebar Assistant**

## Overview

Lumo is an open-source Chrome extension that provides an AI-powered sidebar assistant within your browser. This privacy policy describes how Lumo handles (or does not handle) user data.

## Data Collection

**Lumo does not collect, store, transmit, or share any personal data or user information.**

Specifically, Lumo does NOT:

- Collect browsing history, bookmarks, or download records
- Track user behavior or analytics
- Store personally identifiable information (PII)
- Transmit any data to servers owned or operated by the Lumo developers
- Use cookies or any tracking technologies
- Access user data for advertising or marketing purposes

## Third-Party API Services

Lumo connects to third-party Large Language Model (LLM) API services (such as OpenAI, Anthropic, Google, or other providers) **solely based on user-provided API keys and configuration**. The user is fully responsible for:

- Choosing which third-party API provider to connect to
- Providing their own API credentials
- Understanding and agreeing to the privacy policies and terms of service of their chosen third-party provider

Any data sent to these third-party APIs (such as conversation messages or page content shared during interactions) is governed by the respective third-party provider's privacy policy and terms of service. Lumo acts only as a local client interface and does not intercept, log, or retain any data exchanged between the user and their chosen API provider.

## Local Storage

Lumo may store the following data **locally on the user's device** using the browser's built-in extension storage APIs:

- User preferences and settings (e.g., theme, language)
- User-provided API keys and endpoint configurations
- Conversation history

This data is stored entirely on the user's local device, is never transmitted to any server operated by the Lumo developers, and can be deleted at any time by the user through the extension's settings or by uninstalling the extension.

## Permissions

Lumo requests certain browser permissions (such as access to active tabs or side panel) solely to provide its core functionality — enabling the AI assistant to interact with and assist the user within their browser. These permissions are never used to collect or transmit user data.

## Children's Privacy

Lumo does not knowingly collect any information from children under 13 years of age.

## Changes to This Policy

If this privacy policy is updated, the changes will be reflected in this document with an updated revision date. As an open-source project, all changes are publicly visible in the project's Git history.

## Open Source Transparency

Lumo is fully open source. The complete source code is available at [https://github.com/mscststs/lumo](https://github.com/mscststs/lumo). Users are encouraged to review the codebase to verify the privacy practices described in this policy.

## Contact

If you have any questions or concerns regarding this privacy policy, please open an issue on the [GitHub repository](https://github.com/mscststs/lumo/issues).

---

*This privacy policy applies to the Lumo browser extension distributed via the Chrome Web Store and/or built from source.*
